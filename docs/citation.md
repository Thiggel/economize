# Citation

If you use economize in your research, please cite it:

```bibtex
@software{laitenberger2026economize,
  author  = {Laitenberger, Filipe},
  title   = {economize: Composable Efficiency Techniques for Hugging Face Language Models},
  year    = {2026},
  url     = {https://github.com/Thiggel/economize},
  version = {0.4.0}
}
```

The repository also contains a `CITATION.cff` file, from which GitHub generates the citation in other formats.
Please also cite the papers of the techniques you use. The reference of each technique is given at the end of its
[tutorial](tutorials/index.md).
