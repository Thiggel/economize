# FREE

<!-- technique-info: free -->

FREE (Bae et al., 2023) splits the model into a shallow model, its first `L_S` layers with an exit, and the deep model,
all `L` layers. A token is emitted by the shallow model when its confidence, the gap between the two largest
probabilities of the exit's distribution, reaches the threshold `lambda`. Exited tokens stack up until one does not
exit, and then the deep layers run once, in parallel, over the stacked tokens and that token (synchronized parallel
decoding). The stacked tokens get their deep-layer K/V from this pass, so no hidden state is copied. A shallow token
costs `L_S` of the `L` layers. The method is lossy: every shallow token is kept, and the output differs from the base
model's greedy output wherever the exit is confident and wrong.

economize decodes FREE through its drafting cycle. The shallow model is an early-exit drafter whose drafts are kept
(`lossless=False`), and the draft-length policy `softmax_gap` ends the cycle at the first token below `lambda`. The
exact pass that follows is the synchronized pass and emits that token from the deep model. With `head="shared"` (the
paper) nothing is added to the model, and the `free` objective fine-tunes the model itself. With `head="readout"` a
small readout adapter is trained on the frozen model instead.

## Quick start

`FreeConfig` attaches the shallow exit, and `decode_config` builds FREE's decoding options from its threshold:

```python
from economize.techniques.dynamic_depth import FreeConfig

model = economize.apply(base, FreeConfig(exit_layer=8, threshold=0.9))
free = model.techniques["free"]

result = model.decode(ids[0], 64, decoding=free.decode_config())
print(tokenizer.decode(result.tokens))
print(free.cost_summary(result))       # layer-tokens with the shallow layers the deep pass reuses
```

`free.cost_summary` reports FREE's own cost. economize's exact pass recomputes the shallow layers of the stacked
tokens, which FREE reuses since they are the same layers, and the summary subtracts them (`reused_layer_tokens`).
`threshold=1.0` never exits, which reproduces the base model's greedy output. `max_exits` (31 by default) bounds the
number of consecutive shallow tokens before a deep pass runs anyway; the paper has no such bound.

## Adaptive threshold

The paper sets `lambda` with a two-component Beta mixture over the confidences of tokens on which the shallow and the
deep prediction agree and disagree, and picks the smallest `lambda` whose posterior probability of agreement reaches
`zeta` (`posterior`, 0.4 by default). `free_calibration_pairs` collects the pairs in one teacher-forced pass and
`bmm_threshold` fits the mixture. economize sets the threshold once, offline, where the paper updates it while
decoding:

```python
from economize.techniques.dynamic_depth import bmm_threshold, free_calibration_pairs

confidence, agree = free_calibration_pairs(model, calibration[:8, :512])
lam = bmm_threshold(confidence, agree, posterior=free.config.posterior)
result = model.decode(ids[0], 64, decoding=free.decode_config(threshold=lam))
```

The paper collects the pairs on sequences the model generates itself, so text generated by the base model matches it
more closely than the training data.

## Training

The default objective `free` fine-tunes the model with the weighted cross-entropies of both exits,
`alpha_S = L_S / (L + L_S)` and `alpha_L = L / (L + L_S)`, plus a distillation term that matches each shallow layer
to a deep layer by MSE. `kd_mapping` chooses the layer mapping: `"dynamic"` (the paper's KD-dyna, a monotone map
searched per batch), `"last"`, `"uniform"` or `"none"`:

```python
from economize.techniques.dynamic_depth import FreeObjective
from economize.train import fit

fit(model, "train.bin", FreeObjective(kd_mapping="dynamic", kd_weight=1.0), steps=2000, batch_size=8,
    seq_len=1024, output_dir="runs/free")
result = model.decode(ids[0], 64, decoding=free.decode_config())
```

The objective trains the base weights in place (or the PEFT adapters of a PEFT model). The run writes them to
`runs/free/final/base_parameters.safetensors` and a plain `transformers` copy to `runs/free/final/base/`, as described
in [Training](../training.md). The paper trains encoder-decoder models with AdaFactor, while economize trains
decoder-only models with the trainer's optimizer.

To keep the model frozen, attach the exit with a readout and train it with the early-exit KL objective:

```python
from economize.techniques.early_exit import EarlyExitKL

model.detach()
model = economize.apply(base, FreeConfig(exit_layer=8, head="readout"))
fit(model, "train.bin", EarlyExitKL(technique="free"), steps=2000, batch_size=8, seq_len=1024)
model.save_pretrained("free_readout")
```

## Lossless decoding

An ordinary `DecodeConfig` verifies the shallow tokens instead of keeping them, which turns FREE's exit into a
self-speculative drafter with the base model's greedy output:

```python
model.decode(ids[0], 64, decoding=economize.DecodeConfig(cycle_length=4, min_confidence=0.9,
                                                         draft_policy="softmax_gap"))
```

## Serving

vLLM and SGLang serve the shallow exit through economize's plugins as an early-exit drafter. Served drafts are always
verified, so the served output is lossless:
